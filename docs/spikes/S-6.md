# S-6: camera and mic in use

Run on 2 Nov 2026.

- Mic: `kAudioDevicePropertyDeviceIsRunningSomewhere` on every input device (CoreAudio). 
- Camera: `kCMIODevicePropertyDeviceIsRunningSomewhere` on every CoreMediaIO device.

Both calls ran without any permission prompt and returned `false` while nothing was recording.

## Not verified

The positive case. Nobody was on a call, so there is no evidence yet that a Zoom, Meet or FaceTime call flips these flags. The calls are the documented ones for this and other tools use them, but this run proved only "no prompt, no crash, correct false". Test with a real call before ticking the checklist item.
