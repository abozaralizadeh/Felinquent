# S-3: idle and typing level with no permission

Run on 2 Nov 2026.

`CGEventSourceSecondsSinceLastEventType` with the combined HID state, for any input event and for key-down only, returns seconds as a number. No permission prompt appeared, in the probe or in the Tauri app.

| Call | Result |
|---|---|
| Any input | 56.35 s on the first probe run (real idle time) |
| Key-down only | 418 s (real, the keyboard had not been touched) |

Typing level is derived from the key-down age (under 1 s is `typing_fast`, under 10 s is `typing`). The call returns the age of the last key and never which key, so the hard line still holds.

Note: this is a read of a counter. It does not install an event tap and does not need Input Monitoring.

Not done: a check with someone actually typing. The numbers moved plausibly between runs, but it was not driven by a typist.

Result: **works with no permission**.
